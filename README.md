## 🚀 Features

| **Feature** | **Description** |
|:---|:---|
| **Profile Library** | Organize Smart:EQ 4 profiles by source type and instrument |
| **Session Notes** | Document the audio material used for each learned EQ profile |
| **Correction Log** | Log key frequency corrections made by Smart:EQ per session |
| **Project Mapping** | Track which Smart:EQ profiles are active in each mix project |
